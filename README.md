# Visor de movilidad activa en Chile

Sitio estatico de un solo archivo: `index.html`, con los datos incrustados.

**Este repositorio contiene unicamente el sitio.** El banco de datos, los scripts que lo construyen y su documentacion viven en un repositorio privado aparte y no se publican aca.

Fuentes: Catastro Nacional de Ciclovias (SECTRA/MTT), Censo 2024 (INE), contadores de flujo MINVU, Encuestas Origen-Destino del MTT y siniestralidad CONASET. Elaboracion propia.
